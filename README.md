🧠 South African HIV Data Insights Project
📌 Project Overview

This project focuses on deriving meaningful insights from the South African HIV dataset sourced from Humanitarian Data Exchange
. The goal is to analyze trends and key metrics related to the HIV epidemic in South Africa and present actionable insights through data analysis and visualization.

The dataset provides valuable indicators such as:

PLHIV (People Living with HIV)

New Infections

PLHIV not on ART (Antiretroviral Therapy)

PLHIV unaware of their status

And other relevant HIV-related metrics.

🎯 Objectives

Explore temporal trends across different HIV indicators (e.g., 2017–2024).

Identify patterns across different age groups and genders.

Build interactive dashboards and visualizations to make the data more accessible.

Highlight key areas that require policy attention or public health interventions.

🛠 Tech Stack

Python 🐍

pandas, numpy — data cleaning and analysis

matplotlib, plotly — data visualization

Jupyter Notebook — for analysis and documentation

(Optional) Power BI / Tableau — for interactive dashboards

📊 Key Insights (Examples)

Some preliminary findings include:

A consistently higher awareness of HIV status among women compared to men.

Youth age groups show varying levels of ART coverage and awareness.

A general downward trend in new infections, though some provinces show slower progress.

(More insights will be updated as the analysis progresses.)
